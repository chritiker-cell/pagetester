# ClefBuddy Sight-Reading Level Specification
## Vollständiges Regelwerk für 6 Schwierigkeitsstufen

---

## Level 1: ANFÄNGER (Absolute Beginners)
**Pädagogischer Fokus:** Erste Schritte am Klavier, Notenerkennung in einer Hand, feste 5-Finger-Position

### 1. Notenwerte
```
Erlaubte VexFlow Durations:
- w  (Ganze Note, 4 Schläge)
- h  (Halbe Note, 2 Schläge)
- q  (Viertel Note, 1 Schlag)

VERBOTEN: Achtelnoten, punktierte Noten, Sechzehntel
```

### 2. Handposition & Tonumfang
```
Treble Clef (rechte Hand):
  - Tonumfang: C4 (Middle C) bis G4
  - Position: C-D-E-F-G (5-Finger-Position über C-Dur)
  - Handposition: FEST, keine Lagenwechsel

Bass Clef (linke Hand):
  - Tonumfang: C3 bis G3
  - Position: C-D-E-F-G (5-Finger-Position über C-Dur)
  - Handposition: FEST, keine Lagenwechsel

Spielweise:
  - NUR eine Hand pro Übung (entweder Treble ODER Bass)
  - Keine simultanen Noten zwischen beiden Händen
```

### 3. Intervalle
```
Maximales Intervall: Terz (3 Halbtonschritte)

Gewichtung:
- Unison (Wiederholung): 30%
- Sekunde (Schritt):    50%
- Terz:                 20%
- Quarte+:               0%
```

### 4. Rhythmische Muster (4/4 Takt)
```
Erlaubte Taktmuster:
1. "w"           (eine ganze Note)
2. "h h"         (zwei halbe Noten)
3. "q q q q"     (vier Viertel)
4. "h q q"       (halbe + zwei Viertel)
5. "q q h"       (zwei Viertel + halbe)

Anzahl Takte: 4-8 Takte
```

### 5. Besondere Regeln
```
- Nach jedem Sprung ≥ Terz: nächste Note muss Sekundschritt zurück oder Wiederholung sein (Recovery)
- Melodische Kontur: Maximal 2 aufeinanderfolgende Bewegungen in dieselbe Richtung
- Keine Pausen
- Keine Vorzeichen innerhalb des Taktes
- Kadenz: Letzter Takt endet auf C (Grundton)
```

### 6. Tempo
```
BPM: 60-80 (Viertel = 60-80)
```

### 7. Taktarten
```
Nur 4/4
```

### 8. Tonarten
```
Nur C-Dur (keine Vorzeichen)
```

## Level 2: ELEMENTAR (Early Elementary)
**Pädagogischer Fokus:** Beide Hände zusammenführen, punktierte Halbe einführen, weiterhin feste Handposition

### 1. Notenwerte
```
Erlaubte VexFlow Durations:
- w   (Ganze Note)
- hd  (Punktierte Halbe, 3 Schläge) ← NEU
- h   (Halbe Note)
- q   (Viertel Note)

VERBOTEN: Achtelnoten, Sechzehntel, punktierte Viertel
```

### 2. Handposition & Tonumfang
```
Treble Clef:
  - Tonumfang: C4 bis G4 (identisch zu Level 1)
  - Position: FEST (5-Finger C-D-E-F-G)
  - Handposition: KEINE Änderung während der Übung

Bass Clef:
  - Tonumfang: C3 bis G3 (identisch zu Level 1)
  - Position: FEST (5-Finger C-D-E-F-G)
  - Handposition: KEINE Änderung während der Übung

Spielweise:
  - BEIDE HÄNDE ZUSAMMEN (Grand Staff)
  - Simultane Noten erlaubt (z.B. C4 in Treble + C3 in Bass gleichzeitig)
  - Fokus: Einfache Koordination, oft parallele Bewegung
```

### 3. Intervalle
```
Maximales Intervall: Terz (STRENG begrenzt wegen Koordinationsfokus)

Gewichtung (pro Hand):
- Unison (Wiederholung): 40%
- Sekunde:              45%
- Terz:                 15%
- Quarte+:               0%
```

### 4. Rhythmische Muster (4/4 Takt)
```
Erlaubte Taktmuster:
1. "w"
2. "hd q"        ← NEU (punktierte Halbe + Viertel)
3. "h h"
4. "h q q"
5. "q q q q"
6. "q h q"

Anzahl Takte: 4-8 Takte

Koordinationsmuster:
- Oft identischer Rhythmus in beiden Händen
- Gelegentlich: Treble hat Melodie (q q q q), Bass hat lange Noten (h h)
```

### 5. Besondere Regeln
```
- Recovery nach Terz: Nächste Note muss Sekunde oder Wiederholung sein
- Beide Hände: Maximal 2 Schritte in eine Richtung, dann Richtungswechsel
- Koordination: 60% der Takte haben simultane Note-Onsets
- Keine Synkopen
- Keine Pausen länger als Viertel
- Kadenz: Beide Hände enden auf C
```

### 6. Tempo
```
BPM: 60-90
```

### 7. Taktarten
```
4/4 (primär)
3/4 (optional, einfacher)
```

### 8. Tonarten
```
C-Dur, G-Dur (1 Kreuz)
```

## Level 3: MITTELSTUFE I (Late Elementary)
**Pädagogischer Fokus:** Achtelnoten einführen, Handposition darf sich ändern, größere Intervalle

### 1. Notenwerte
```
Erlaubte VexFlow Durations:
- w   (Ganze)
- hd  (Punktierte Halbe)
- h   (Halbe)
- q   (Viertel)
- 8   (Achtel) ← NEU

VERBOTEN: Punktierte Achtel, Sechzehntel
```

### 2. Handposition & Tonumfang
```
Treble Clef:
  - Tonumfang: G3 bis C5 (eine Oktave Erweiterung)
  - Position: VARIABEL (Lagenwechsel erlaubt)
  - Maximaler Lagenwechsel: 1x pro 4 Takte

Bass Clef:
  - Tonumfang: F2 bis F3 (erweitert)
  - Position: VARIABEL
  - Maximaler Lagenwechsel: 1x pro 4 Takte

Spielweise:
  - Beide Hände zusammen (Grand Staff)
  - Unabhängigere Rhythmen zwischen den Händen
```

### 3. Intervalle
```
Maximales Intervall: Quinte (7 Halbtonschritte)

Gewichtung (pro Hand):
- Unison:    25%
- Sekunde:   35%
- Terz:      25%
- Quarte:    10%
- Quinte:     5%
- Sexte+:     0%
```

### 4. Rhythmische Muster (4/4 Takt)
```
Erlaubte Taktmuster:
1. "w"
2. "hd q"
3. "h h"
4. "h q q"
5. "q q q q"
6. "q q h"
7. "8 8 8 8 8 8 8 8"  ← NEU (acht Achtel)
8. "q 8 8 q q"        ← NEU (gemischt)
9. "h 8 8 8 8"        ← NEU

Anzahl Takte: 8-12 Takte

Achtel-Regel:
- Achtel nur in Zweiergruppen (Beams) ← wichtig für Lesbarkeit
- Maximal 4 aufeinanderfolgende Achtel am Stück
```

### 5. Besondere Regeln
```
- Nach Sprung ≥ Quarte: Recovery mit Sekundschritt oder Wiederholung
- Lagenwechsel: Muss über Pausenübergang oder lange Note (≥ halbe) erfolgen
- Phrasierung: 2- oder 4-taktige Phrasen
- Pausen: Viertel- und halbe Pausen erlaubt
- Einfache Dynamik-Hinweise optional (f, p)
```

### 6. Tempo
```
BPM: 72-100 (Viertel)
Bei Achtelnoten: 60-80 empfohlen
```

### 7. Taktarten
```
4/4, 3/4, 2/4
```

### 8. Tonarten
```
C-Dur, G-Dur, F-Dur (bis 1 Vorzeichen)
a-Moll, e-Moll, d-Moll (natürlich/harmonisch)
```

## Level 4: MITTELSTUFE II (Early Intermediate)
**Pädagogischer Fokus:** Punktierte Achtel, einfache Akkorde (Zweiklänge), komplexere Rhythmen

### 1. Notenwerte
```
Erlaubte VexFlow Durations:
- w   (Ganze)
- hd  (Punktierte Halbe)
- h   (Halbe)
- qd  (Punktierte Viertel) ← NEU (teilweise in Level 3 vorbereitet)
- q   (Viertel)
- 8d  (Punktierte Achtel) ← NEU
- 8   (Achtel)
- 16  (Sechzehntel, nur nach punktierter Achtel) ← NEU, limitiert
```

### 2. Handposition & Tonumfang
```
Treble Clef:
  - Tonumfang: F3 bis E5 (über eine Oktave)
  - Position: Frei beweglich
  - Lagenwechsel: Beliebig oft

Bass Clef:
  - Tonumfang: E2 bis A3
  - Position: Frei beweglich
  - Lagenwechsel: Beliebig oft

Spielweise:
  - Beide Hände, unabhängige Stimmen
  - Akkorde: Zweiklänge (Intervalle) in einer Hand erlaubt
```

### 3. Intervalle
```
Maximales Intervall: Sexte (9 Halbtonschritte)

Gewichtung (melodisch, pro Hand):
- Unison:    20%
- Sekunde:   30%
- Terz:      25%
- Quarte:    12%
- Quinte:     8%
- Sexte:      5%
- Septime+:   0%

Akkorde (harmonisch, simultan in einer Hand):
- Zweiklänge erlaubt: Terzen, Quinten, Sexten
- Häufigkeit: 10-20% der Noten
```

### 4. Rhythmische Muster (4/4 Takt)
```
Erlaubte Taktmuster:
1. Alle aus Level 3
2. "qd 8 q q"         ← Punktierte Viertel + Achtel
3. "8d 16 8d 16 q"    ← NEU: Punktierte Achtel + Sechzehntel
4. "q q qd 8"
5. "8d 16 q 8d 16 q"

Anzahl Takte: 8-16 Takte

Sechzehntel-Regel:
- Nur im Muster "8d 16" (Scotch Snap / Lombardischer Rhythmus)
- KEINE langen Sechzehntel-Läufe
```

### 5. Besondere Regeln
```
- Akkorde: Nur konsonante Intervalle (Terz, Quinte, Sexte, Oktave)
- Nach Sexte-Sprung: Recovery mit Schritt oder Terzgegenbewegung
- Synkopen: Einfache Synkopen erlaubt (q-Offbeat)
- Artikulation: Legato-Bögen, Staccato-Punkte optional
- Dynamik: f, mf, mp, p, crescendo/decrescendo
```

### 6. Tempo
```
BPM: 80-108 (Viertel)
Bei punktierten Achteln: 72-96 empfohlen
```

### 7. Taktarten
```
4/4, 3/4, 2/4, 6/8 (einfache Teilung)
```

### 8. Tonarten
```
Bis 2 Vorzeichen:
- Dur: C, G, D, F, Bb
- Moll: a, e, d, g, c (harmonisch/natürlich)
```

## Level 5: FORTGESCHRITTEN I (Intermediate)
**Pädagogischer Fokus:** Dreiklänge, schnellere Passagen, erweiterte Rhythmik, erste polyphone Elemente

### 1. Notenwerte
```
Erlaubte VexFlow Durations:
- Alle aus Level 4
- 16  (Sechzehntel, jetzt in Vierergruppen) ← erweitert

Triplets:
- 8 8 8 (Achtel-Triolen) ← NEU
```

### 2. Handposition & Tonumfang
```
Treble Clef:
  - Tonumfang: E3 bis G5 (über 2 Oktaven)
  - Position: Unbegrenzt

Bass Clef:
  - Tonumfang: C2 bis C4
  - Position: Unbegrenzt

Spielweise:
  - Polyphone Ansätze (2 Stimmen in einer Hand möglich)
  - Dreiklänge in beiden Händen
```

### 3. Intervalle
```
Maximales Intervall: Oktave (12 Halbtonschritte)

Gewichtung (melodisch):
- Unison:    15%
- Sekunde:   25%
- Terz:      25%
- Quarte:    15%
- Quinte:    10%
- Sexte:      5%
- Septime:    3%
- Oktave:     2%

Akkorde:
- Dreiklänge (Grundstellung, 1. + 2. Umkehrung)
- Häufigkeit: 20-30% der Noten
```

### 4. Rhythmische Muster (4/4 Takt)
```
Komplexe Muster:
1. "16 16 16 16 q q q"    ← Sechzehntel-Vierergruppen
2. "8 8 8 q 8 8 8"        ← Triolen-Notation (8t 8t 8t)
3. "q 16 16 16 16 h"
4. "8d 16 8d 16 8d 16 q"
5. Synkopierte Muster

Anzahl Takte: 12-16 Takte
```

### 5. Besondere Regeln
```
- Arpeggios über Akkordtöne erlaubt
- Sequenzierung: Motive dürfen transponiert wiederholt werden
- Chromatik: Durchgangstöne, Wechselnoten erlaubt
- Pedal-Markierungen optional
```

### 6. Tempo
```
BPM: 88-120 (Viertel)
Bei Sechzehnteln: 72-100
```

### 7. Taktarten
```
4/4, 3/4, 2/4, 6/8, 3/8, 2/2 (Cut Time)
```

### 8. Tonarten
```
Bis 3 Vorzeichen:
- Dur: C, G, D, A, F, Bb, Eb
- Moll: a, e, b, d, g, c, f
```

## Level 6: FORTGESCHRITTEN II (Advanced)
**Pädagogischer Fokus:** Konzertreife Sight-Reading, komplexe Polyrhythmik, erweiterte Harmonik

### 1. Notenwerte
```
Alle Notenwerte erlaubt:
- w, hd, h, qd, q, 8d, 8, 16d, 16, 32

Triplets & Quintuplets:
- Triolen in allen Notenwerten
- 5:4, 6:4 Teilungen (optional)
```

### 2. Handposition & Tonumfang
```
Treble Clef:
  - Tonumfang: A2 bis C6 (voller Klavierumfang für rechte Hand)

Bass Clef:
  - Tonumfang: A1 bis E4

Spielweise:
  - Vollständig polyphon (bis zu 3 Stimmen pro Hand)
  - Vierstimmige Akkorde
  - Kreuzungen zwischen Händen möglich
```

### 3. Intervalle
```
Alle Intervalle erlaubt, inkl. Oktaven und darüber hinaus.

Gewichtung:
- Ausgeglichen über alle Intervalle
- Chromatik: 10-15% der Bewegungen

Akkorde:
- Vierstimmige Akkorde (7th-Chords)
- Alterierte Akkorde
- Häufigkeit: 30-40%
```

### 4. Rhythmische Muster
```
Alle rhythmischen Figuren erlaubt:
- Komplexe Synkopen
- Hemiolen (3 gegen 2)
- Polyrhythmik zwischen Händen
- Rubato-Passagen (tempo-variabel)

Anzahl Takte: 16-32 Takte
```

### 5. Besondere Regeln
```
- Modulationen innerhalb der Übung erlaubt
- Chromatische Skalen, verminderte/übermäßige Intervalle
- Arpeggios über 2 Oktaven
- Glissandi, Triller, Verzierungen (optional)
- Pedalgebrauch notiert
```

### 6. Tempo
```
BPM: 96-144 (Viertel)
Variable Tempi innerhalb der Übung (rit., accel.)
```

### 7. Taktarten
```
Alle gängigen Taktarten:
4/4, 3/4, 2/4, 6/8, 9/8, 12/8, 5/4, 7/8, 2/2, etc.

Taktwechsel innerhalb der Übung erlaubt.
```

### 8. Tonarten
```
Bis 5 Vorzeichen (optional bis 7):
- Alle Dur-Tonarten bis E-Dur (4#), Db-Dur (5b)
- Alle Moll-Tonarten entsprechend

Kirchentonarten (Modi) optional:
- Dorisch, Phrygisch, Lydisch, Mixolydisch
```

## Implementierungs-Hinweise

### VexFlow Duration Mapping
```typescript
const DURATION_MAP = {
  'w': 'whole',
  'hd': 'half-dotted',
  'h': 'half',
  'qd': 'quarter-dotted',
  'q': 'quarter',
  '8d': 'eighth-dotted',
  '8': 'eighth',
  '16d': '16th-dotted',
  '16': '16th',
  '32': '32nd'
};
```

### Tonumfang-Notation
```
C4 = Middle C (eingestrichenes C)
C3 = kleine Oktave
C5 = zweigestrichene Oktave
```

### Algorithmus-Parameter pro Level
```typescript
interface LevelConfig {
  level: number;
  durations: string[];              // Erlaubte VexFlow durations
  trebleRange: [string, string];    // [min, max] z.B. ['C4', 'G4']
  bassRange: [string, string];
  maxInterval: number;              // Halbtonschritte
  intervalWeights: {
    unison: number;
    second: number;
    third: number;
    fourth: number;
    fifth: number;
    sixth: number;
    seventh: number;
    octave: number;
  };
  handsMode: 'single' | 'together' | 'independent';
  positionFixed: boolean;
  allowChords: boolean;
  chordTypes: string[];             // ['interval', 'triad', 'seventh']
  rhythmPatterns: string[][];       // Array of patterns
  timeSignatures: string[];
  keySignatures: string[];
  tempoRange: [number, number];     // [min, max] BPM
  measureCount: [number, number];   // [min, max]
}
```

## Validierungs-Checkliste

Jede generierte Übung MUSS folgende Kriterien erfüllen:

### ✓ Rhythmus
- [ ] Taktfüllung korrekt (Summe der Notenwerte = Taktart)
- [ ] Nur erlaubte Notenwerte für Level verwendet
- [ ] Balkensetzung korrekt (Achtel/Sechzehntel gruppiert)

### ✓ Tonhöhe
- [ ] Alle Noten innerhalb des erlaubten Tonumfangs
- [ ] Maximales Intervall nicht überschritten
- [ ] Recovery-Regel nach großen Sprüngen eingehalten
- [ ] Handposition-Regel beachtet (Level 1-2: fix)

### ✓ Harmonik
- [ ] Tonart korrekt (Vorzeichen am Anfang)
- [ ] Akkordtöne entsprechen der Tonart
- [ ] Kadenzschluss auf Grundton

### ✓ Pädagogik
- [ ] Melodische Kontur ausgewogen (nicht nur aufwärts/abwärts)
- [ ] Phrasenstruktur erkennbar (2/4/8 Takte)
- [ ] Schwierigkeit konsistent über die Übung
- [ ] Keine unspielbare Fingersätze (Handspannweite beachten)
